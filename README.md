# Tanjim Ahmed Portfolio

A responsive portfolio website built with React, Tailwind CSS, and Vite.

## New updates included

- Added Tanjim Ahmed's profile photograph to the hero and navigation areas.
- Added a complete Education section using the supplied CV.
- Added the personal video presentation near the end of the portfolio.
- Converted the original HEVC `.MOV` video to a smaller browser-compatible H.264 `.mp4` file.
- Added the supplied CV as a downloadable PDF.
- Updated contact links using the information in the CV.
- Refined skills and project descriptions to match the CV.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually `http://localhost:5173/`.

## Build for deployment

```bash
npm run build
```

The production files will be created in the `dist` folder.

## Main files

- `src/App.jsx` — page content and sections
- `src/index.css` — shared styling
- `public/media/tanjim-ahmed.webp` — profile image
- `public/media/tanjim-video-presentation.mp4` — video presentation
- `public/Tanjim_Ahmed_CV.pdf` — downloadable CV
