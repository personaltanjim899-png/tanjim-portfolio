# Tanjim Ahmed Portfolio

A professional React + Tailwind CSS + Vite portfolio website for Tanjim Ahmed.

## Included

- Responsive portfolio design
- Hero section
- About and education section
- Technical skills section
- Research experience section
- RTL / VLSI / verification project cards
- Certificate gallery with image preview modal
- Training summary section
- Contact section
- Downloadable portfolio PDF

2. ULKASEMI Pvt. Limited — Industrial Training Program
3. ChipXpert Technologies Private Limited — VLSI Design & Semiconductor Industry Workshop

## How to Run

Open the project folder in VS Code, then run:

```bash
npm install
npm run dev
```

Then open the local link shown in the terminal, usually:

```bash
http://localhost:5173/
```

## Build for Deployment

```bash
npm run build
```

The production-ready files will be generated in the `dist` folder.

## What to Edit Before Publishing

Open `src/App.jsx` and replace these placeholders:

- `your.email@example.com`
- LinkedIn URL
- GitHub URL
- Phone number

You can also add more projects by editing the `projects` array inside `src/App.jsx`.
